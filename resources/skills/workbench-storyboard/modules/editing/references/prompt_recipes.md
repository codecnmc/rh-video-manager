# 可直接调用的任务提示词

2026-10-23 合并适配：从导演工作台进入剪辑部分，工具能力以实际工作台为准。

## 建立素材目录

```text
调用 director-workbench 的剪辑部分。逐个解码指定目录的视频和音频，建立镜头目录、接触表和技术 QC。全片先以 4 FPS 扫描；动作、视线变化、手部动作和剪切候选区提高到源帧率复扫。不要修改 NLE。
```

## 表演精选

```text
比较同一场戏的全部 take，重点看动作前的意图、动作后的反应、视线方向、身体重心、呼吸和前后把手。给出 top 3，并引用准确源时间码和证据帧。不要只比较单张好看的帧。
```

## 粗剪计划

```text
根据脚本和 shots.jsonl 设计一个 45 秒粗剪。每个 cut 标记理由：信息、表演、动作匹配、视线、空间、节奏、声音桥或故意断裂。先输出 edit_plan.json，不修改 Resolve。
```

## 应用到 Resolve

```text
读取并验证 edit_plan.json。查询 Resolve 当前项目和时间线，复制目标时间线为带日期版本，再分批应用剪辑。每批后回读实际位置。保留原音、调色和标记；不删除原时间线。最后输出 changelist。
```
