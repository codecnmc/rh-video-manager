# RH H3 全能参考格式

本文件限定全能参考 Ref2VA，不把仅首尾帧模式的三字段格式混入全能参考。正文默认中文；以下字段名及协议值保持不变。

## 六节顺序

1. `subject_definitions`：逐项定义引用职责和来源。
2. `summary`：以方括号内任务类型开始，用一段中文交代目标和主要参考关系。
3. `retention_analysis`：每个被单独使用的引用一行，写角色范围与保留关系。
4. `detailed_description`：按播放顺序写画面、动作、摄影机、对白与声音。
5. `overall_soundscape`：全段环境声、物理声和非语言人声；不重复对白。
6. `non_diegetic_music`：观众听到、角色听不到的配乐，无配乐写 `N/A`。

## 标签及关系

- `<Subject N>` 是可复用可见内容，如人物、道具、环境；在定义中注明来自哪一张实际图片或视频。它不是一个需要上传的素材编号。
- `<Picture N>` 是实际绑定图片。作为首帧、关键帧、尾帧、构图锚点时才单独定义；只作人物参考时在 Subject 定义中引用即可。
- `<Video N>` 是实际绑定视频，用于续接、编辑或时序/镜头参考。可见人物仍分别定义 Subject。
- `<Audio N>` 是实际绑定的音频信号或明确启用的视频同步音轨；不能因为视频文件里原本有声音就自动创建。编号按各自类别独立，并不和 Video 数字成对。
- 标签在六节中保持一致。上传素材编号必须来自应用绑定结果，不能据本示例照抄。

summary 的固定任务类型可按实际关系以 ` + ` 合并：

- `video continuation`：从源视频末尾继续新内容。
- `keyframe completion`：图片作为明确时刻的画面锚点。
- `reference generation`：仅参考人物、风格、动作或镜头，不是续接/编辑原视频。
- `video editing`：直接修改既有视频；只写后续新段落不是此类型。
- `audio reuse`：复制原音频信号；`audio reference`：只参考音色、节奏等，不复制信号。

可见引用使用固定关系 `fully_preserved`、`partially_preserved`、`attribute_transfer`、`weak_reference`。音频使用 `fully_copy`、`partially_copy`、`reference`、`weak_reference`。关系描述只针对该引用已定义的职责，不能把新剧情视作身份丢失。

## 镜头与声音

风格在 detailed_description 开头以一两句中文说明，连续镜头应继承实际参考，不重新创作光色。第一镜用 `[Shot 1]`，不带时间戳；只有真正切镜才写 `[Shot 2] At 00:03.000, ...`，时间递增且在片段内。连续单镜不为每个动作人为添加 Shot。

每镜交代可见构图、人物相对位置、衣着与道具、环境照明、动作变化、镜头运动和当前声音。摄影机运动要有方向，必要时补幅度与速度。不要用剧情概括代替可见行为；中文不机械套用 350–500 英文词数。

实际发声者用稳定 `(S1)`、`(S2)`，跨镜不重编号，Subject 与说话者分别编号。人物发声用 `<Subject 1> (S1)`；不发声者不编说话者编号。对白用 `<d>[Chinese] 原始台词</d>`，动作和语气放在标签外。画外声写明来源且人物嘴唇闭合。跨切镜连续对白按需要用 `<scenetrans>`，片尾截断用 `<cutoff>`，不可无故截断用户台词。可见文字保留原文并用英文双引号包裹。

纯静音、闭唇默演及用户指定的空对白标签遵循 [guide.md 的声音意图规则](../guide.md#声音意图闭唇与静音)：空标签写 `<d></d>`，不是 `D:[]`，不在标签内填静音指令。完全静音时两个声音字段均写 `N/A`，且不使用音频引用；空标签不保证输出必然静音，仍须核验预览音轨与口型。

## 连续镜头写法示意

以下是说明，不是可直接提交的完整提示词。只有工具实际返回相同标签时才能采用这些编号；不要把省略号写入成稿。

```text
subject_definitions:
<Video 2> 是上一段已确认的 5 秒成片最后 1 秒的无声尾段，提供末尾的实际机位、光色和动作速度；实际时长选择遵循 ../guide.md 的尾段规则（2026-10-23 合并后路径）。
<Picture 4> 是同一源视频的真实最后帧，作为本段 0 秒画面锚点。
<Subject 1> 是 <Video 2> 中的人物，身份、服装和当下站位均沿用实际尾段。

summary:
[video continuation + keyframe completion] 从 <Video 2> 的最后时刻之后继续一个新的 5 秒单镜头，0 秒衔接 <Picture 4>，不重播参考尾段。

retention_analysis:
<Video 2> (末尾视觉属性与运动趋势): partially_preserved - 只延续结尾属性，不复制参考时间序列、旧动作或声音。
<Picture 4> ([Shot 1] 0 秒锚点): fully_preserved - 保持同源末帧的构图与曝光。
<Subject 1> (appears in [Shot 1]): fully_preserved - 延续可见身份、服装与位置。
```

之后必须根据实际素材与用户的新动作补全 detailed_description、overall_soundscape 和 non_diegetic_music，不得凭本示意编造人物、机位和台词。

## 声音与时长检查

人物声音与对白演绎遵循 [台词、声线与有因表演](../../../references/dialogue-performance.md)：稳定声线和逐句演绎分开，演绎说明在 `<d>` 外；情绪触发与动作、表情、语气按因果顺序写在 `detailed_description`，不新增协议字段。

先继承分镜的生成内/后配清单。`overall_soundscape` 只允许生成内声音并明确排除后配音效；后配仍保留可见动作及同步节奏，不让模型同步再做一份拟音。后配配乐写 `non_diegetic_music: N/A`。后配制作清单单独交接，不新增协议字段，不把待找音频当成已绑定 Audio。

overall_soundscape 先列全段允许出现的声音，包含片头余量。参考视频无音轨不等于模型不会联想出门铃等声音；已完成的事件不重新拟音。Audio 声线参考用 reference，不误写 audio reuse 或 fully_copy。

目标成片时长、生成请求时长、实际输出时长和参考长度分开填写。默认不加减参考时长；用户同意的剪辑余量须标明为计划，不宣称必然可裁。验收后依真实重复范围与对白起止决定入点，不能按引用秒数盲切。仅抽帧时明确音轨未核验。
