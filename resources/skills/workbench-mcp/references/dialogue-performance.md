# 台词、声线与有因表演

设计人物对白、声音情绪或情绪变化时读取。分镜负责确定表演动机和节拍，提示词忠实编译已定表演，不借补情绪改写剧情。保留用户原台词；未明确的信息可作符合现有角色的设计建议，不把建议冒充剧本事实，不擅自补职业、身世或新事件。

## 稳定声线：先确认引用，再描述人声

- 已指定音色或音频引用时，以用户指定及真实引用职责为准；只参考声线不等于复用原台词、波形、语气或背景声。不得用另一套文字声线覆盖已定音色，不伪造 Audio 标签。
- 没有指定音色或音频引用时，按“职业身份 + 性别 + 年龄 + 音高 + 声音质地 + 发声特点”描述每位实际发声者。闭唇默演或纯静音人物不定义声线和说话者编号，遵循 [提示词模块的声音意图规则](../modules/prompt/guide.md#声音意图闭唇与静音)。职业身份采用已知角色设定，不由职业推导刻板口音；未知项标为未定或给出建议，不为填满模板编造事实。性别、年龄描述声音呈现，不推断真人隐私。
- 音高写低、中、高及适度音域；质地写清亮、温润、干涩、沙哑、带颗粒感等听觉特征；发声特点写共鸣位置、咬字、气息、气声比例、尾音习惯等。选能共同成立的特征，不堆砌互相矛盾的形容词。“有磁性”“有感情”不能单独承担声线定义。
- 同一人物跨句、跨镜保持这套稳定声线；当下紧张、疲惫或哭泣只改变本句演绎，不重新指定年龄、基础音高或声音身份。不要用升调等同开心、低沉等同悲伤。

示例声线（仅用于已知或已批准设定）：急诊医生，女性，约35岁，中低音，音质清晰略干，共鸣靠前、咬字利落、气息支撑稳定，平常收尾短而干净。

## 每句对白：语气 + 节奏 + 状态 + 标点

- **语气**：写人物此刻对谁、想做什么，以及如何说，例如压住责备试探、克制地确认、强撑镇定安抚；“愤怒地说”过于笼统。语气来自本句意图与眼前刺激，不只是情绪标签。
- **节奏**：交代起句快慢、停顿位置、重读词、加速/放慢和句尾收束。按语义与情绪转折安排，不给每个字标动作，也不默认每句话都颤抖、拖长或大喊。
- **状态**：写当下影响发声的身体与心理控制状态，如刚跑停后气息未匀、哽住后吞咽再开口、压着音量避免被门外听见；只使用情境支持的状态。区分声音质地与暂时性的喘息、破音、哽咽。
- **标点**：用逗号、句号、问号、破折号、省略号等帮助表达句法、停顿与未尽之意，不堆叠“！！！/？？？”代替表演。用户原文及标点默认保留；需要改标点时先在标签外描述停顿，只有获准润色台词才改写正文。停顿、重读和动作指令不塞进要被念出的台词。
- 对白须能在指定时长内自然说完，并给感知、反应和呼吸留空间。放不下时说明时长冲突，提出精简或调整节拍的建议，不静默删字、倍速念白或挤掉触发事件。

## 情绪必须有发生原因

按“事件原因 → 人物看到/听到/亲历的具体刺激 → 感知与反应 → 动作、表情、说话语气 → 后续变化”建立可拍、可听的因果链。事件可以发生在镜前或画外，但须有剧本或已定上下文依据；不为制造情绪新增事故、误会、回忆或秘密。

- 区分观众知道与人物知道。角色只有在看到、听到或经历相关刺激之后才产生相应反应；未知消息不能提前触发惊恐。延迟反应、掩饰或误解可以成立，但要有上下文依据。
- **动作**：写可见且有对象的反应，例如手停在门把上、伸出的手收回、往声源方向转头；不是抽象的“悲伤起来”。
- **表情**：写变化过程与强度，例如目光先停住、眉间收紧、嘴角原有笑意消失；不同时堆满瞪眼、落泪、咬牙等强烈符号。
- **说话语气**：写同一刺激怎样改变声音，例如先吸气压住声音，起句试探，听到回答后尾句转硬。动作、表情、语气共同服务同一动机，不要求三者同强度或同一瞬间出现；强装轻松时可形成有意反差，但须说明掩饰原因。
- 情绪沿时间发展，不在下一句或切镜后无缘无故重置。继承上一镜末态；刺激未变时不反复从平静重新演到崩溃。人物内心判断可辅助设计，交付模型时要落为可见行为、可听声音及其先后关系。
- 因果依据不足时保留原剧情，标注待确认，不凭空补一个理由。仅改提示词时，把已有因果写清即可，不重新导演已锁定分镜。

## 写入六节提示词的位置

声线描述放在 `detailed_description` 的人物首次发声处，并沿用稳定说话者编号；有真实引用时，引用职责仍放 `subject_definitions` / `retention_analysis`。情绪触发、动作、表情、语气、节奏与状态按发生顺序写入对应镜头，对白正文仍用 `<d>[Chinese] 原始台词</d>`，演绎说明写在标签外。不新增 `voice_profile` 等协议字段，不把对白复制进 `overall_soundscape`。

需要对口型的后配对白仍设计上述表演与口型时序，但声线及配音执行要求交给正文外的后配清单；不要求视频模型再生成一份对白。闭唇默演不是对口型后配，不为它补开口动作。只写文字时不虚称已听验情绪或音色一致。

## 简短示例与复核

以下假设“医生听到同伴确认未找到患者”已在剧本中，不作为新增剧情：

> 同伴在画外说完“还没找到”。医生听到后，原本伸向病历的手停住，目光从纸面移向同伴，眉间逐渐收紧；先短吸气再压稳气息，以克制的确认语气开口，起句稍慢，重读“再”，句尾收住而不喊叫：<d>[Chinese] 你再说一遍。</d>

提交前逐项看：无引用时声线六要素是否明确或诚实标未定；每句是否具备语气、节奏、状态和合适标点；情绪是否有角色实际感知的原因；动作、表情、语气是否有先后与统一动机；原台词、稳定声线、时长及生成内/后配边界是否保留。复核用于修稿，不强制把检查表附在每次交付里。
