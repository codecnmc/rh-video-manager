# AI 视频工作台可选 MCP 接入

接入此软件时读取；无 MCP 仍可使用用户提供的剧本、本地图片/视频，交付文本、生成图与手工导入清单。技能不绑定 Codex，也不自动修改任何客户端配置。素材生成说明于2026-10-28对照代码提交 `512731c` 与当前会话工具补充；每次仍先发现运行时工具与 schema，不把已提交代码当作运行实例已升级或验收通过。

## 连接与授权

请用户在工作台 MCP 面板选择单个项目或显式全部项目，默认只读；需要导入图/保存草稿才开启写入并选择导入目录。有效期 5–120 分钟或 -1；手动关闭、退出、到期仍撤销访问。剧本库与排片剪辑访问单独勾选，不为看图擅自扩大权限。

软件开启后使用“复制 MCP 配置”，把配置交给用户所用客户端的 MCP 管理界面或配置文件。服务为本机 Streamable HTTP：`http://127.0.0.1:5189/mcp`，以 `Authorization: Bearer <用户本地令牌>` 认证。复制配置含凭据，不回显到聊天/日志、不打包进技能，不要求用户公开粘贴。保留回环地址、Host/Origin 校验，不暴露公网、不代理绕过。未连接先给这段操作说明，可继续不依赖连接的工作。

## 已核实工具和边界

### 连接后先查询授权导入目录

直接连接 MCP 后，先发现运行时工具并调用 `assets_import_directory`（无参数），读取 `writeEnabled`、`importDirectory`、`expiresAt`；重新连接和每次本地导入前重新查询，不猜目录、不读取配置或数据库寻找路径。只读会话目录为 null；工具缺失时说明运行实例需要加载更新并重新连接，不能把源码支持当作当前可调用。

用户已要求导入或绑定本次参考图时，核实来源文件可读，将授权目录外的该文件复制到授权目录中的唯一新文件名，再用该绝对路径调用 `assets_import`；不移动或覆盖原件，不扫描目录，不复制无关文件。文件本已在授权目录内则直接导入。返回目录仅对同一电脑有效，不是任意磁盘读取/写入或上传、付费生成的授权；没有获准的本地复制能力时请用户手动放入。

只读、目录为空、会话失效、工具缺失或复制失败时停在导入步骤，明确缺少的权限/能力；不要盲试临时附件路径或反复重试通用错误。导入后查询真实素材 ID 和最新 updatedAt，再绑定并回读确认；参考图未绑定不得声称已使用，也不得把缺少身份参考的草稿称作可直接生成。

| 用途 | 工具与注意事项 |
|---|---|
| 找项目与素材 | 全项目授权才有 `projects_list`；`asset_categories`、`assets_list` 查询文件夹/素材，列表分页每次至多100条；明确项目ID与公共素材范围 |
| 读取图片原图 | `assets_read_image` 使用素材ID及 `assets_list` 返回的最新 `updatedAt`；当前支持PNG/JPEG/WebP、最大10MB，返回原始图片与修订元数据，不缩放裁剪、不上传 |
| 读剧本 | 单独授权后 `script_library_list/get`；更新前读 revision，只有获准修改剧本才用 save |
| 草稿与分组 | `video_groups_list`、`video_drafts_list`；可写时 `video_group_save`、`video_draft_save`，草稿保存须完整字段及最新 revision，不上传、不生成 |
| 本地导入图片 | `assets_import`，只接受授权导入目录内绝对路径，每批至多20个；回读真实素材ID，勿把输出文件路径当 assetId |
| 引用图片/音视频 | `video_draft_reference_attach/detach`；使用返回的真实 Picture/Video/Audio 标签，不猜编号；改绑定后重新读取 revision |
| 连续镜头 | `video_continuity_list`；可写并获准本地衍生时 `video_continuity_prepare`，精确匹配项目/草稿/job/source；尾段长度遵循提示词模块 |
| 检查视频/音频 | 单独排片授权下 `assembly_inspect_media`：先不传 times 查询实际时长，再至多6个时点取 JPEG，最长边960；不支持静态图片、不提供独立听审 |
| 排片与声音计划 | 单独排片授权后 `assembly_list/get`；可写时 `assembly_save` 保存版本化快照及声音需求/绑定，不混音、不导出 |
| 素材生成任务组 | 开放后 `image_boards_list`、`image_nodes_list`；协议保留 board/node 名称，软件界面为任务组、任务网格及编辑区，不再要求无限画布操作 |
| 创建生图草稿 | 生图访问及写权限下 `image_board_create`、`image_node_create`，仅本地保存；字段、引用与幂等约束见下文 |
| 生图状态与故障 | `image_node_diagnose` 只诊断已有缓存及下载网络；开放 `image_output_recover` 时可恢复既有结果，不重新生图 |
| 删除生图任务 | 仅在运行时开放 `image_nodes_delete` 且用户授权时软删除；不删除结果素材，不取消远端请求，不靠隐藏节点代替删除 |
| 提交生图 | 仅在独立提交权限及运行时开放 `image_nodes_submit` 时可执行，会收费且不逐笔弹窗；素材写权限、创建草稿或技能加载都不授权提交 |

连接权限不能代替用户操作授权。所有写入前确认目标、最新修订，复用同一请求的 requestKey；冲突重新读取并合并，不盲目覆盖。`assembly_save` 是完整快照，保留未涉及版本、片段和声音需求；不可省略它们造成隐式移除。具体声音时间语义先核对运行时契约/工程，不臆造字段。

## 素材生成任务组、版本与重试

### 查询、草稿与引用

- 先查项目及 `image_boards_list`，再用 `image_nodes_list` 查询任务；需要审核/复制完整提示词时显式 `includePrompts=true`，按 offset 读完分页。任务状态、任务修订与素材 updatedAt 分别管理。历史 hiddenNodeIds 只表示旧界面的隐藏项，不是任务删除，也不算有效待生成清单。
- 创建任务组使用 UUID `id`、明确 `projectId`（公共素材为 null）、title 和 requestKey；在全项目授权下明确目标，不能猜当前界面选中的项目。已有任务组不重复创建。
- `image_node_create` 使用新的 UUID id、boardId、title、完整 prompt、明确 size、accountId、references 及 requestKey。引用每项是 `{assetId, expectedUpdatedAt}`，使用实际查看且合格的图片与最新修订，按顺序绑定；生成结果未审核通过不得自动用于下游。尺寸和引用上限以运行时及协议能力为准，不把本地路径、URL 或 API Key 当引用字段。
- `accountId=null` 表示由工作台按兼容能力和真实账号组并发自动调度；显式指定账号使用软件的真实 ID，不使用包内脚本 providerId。开放 `image_protocols_list` 时可查询能力，但返回的操作标记不能替代实际工具是否存在及用户授权。
- 创建返回 draft 只证明本地草稿已保存，不表示已经上传、生成、审核或完成。创建后回读确认，向用户分别报告已有结果、待提交、在途和异常任务。已登记结果使用真实 assetId 查库并读原图，不重复 assets_import。

### 修改与版本

软件右侧编辑区可修改可编辑草稿的提示词、尺寸、账号和引用图，引用支持添加、移除和排序；已提交输入冻结，修改需创建新版本。当前不要假设存在 MCP 任务编辑工具：运行时未开放时由用户在软件编辑，或按本轮授权建立新草稿，不伪造 save 工具。

新版创建契约支持可选 `sourceNodeId`，指向同一任务组的原任务，用于保留版本关系；只在当前 `image_node_create` schema 实际列出此字段时传入。新版本使用新 id 与新请求键，保留原任务、原提示词和结果，不复用旧 id 改内容，不按名称推断版本关系。旧运行时不支持此字段时，说明限制并请用户在已更新软件内创建新版本，不静默省略关系后声称版本已关联。

多窗口中保存前查询最新修订；发现冲突重新读取并保留本地未保存修改，不能用旧快照覆盖另一窗口结果。运行实例仍显示旧字段或缺工具时，报告需更新运行实例/重新连接，不自行重启应用或扩大权限。

### 生成、恢复与重试的区别

| 实际状态 | 处理方式 |
|---|---|
| draft / not_submitted | 确认任务输入与当前授权后可提交；not_submitted 的错误先查清，也可按用户要求新建重试版本，不擅自自动重提 |
| queued / preparing / generating / downloading | 仍在途，不复制成付费重试；撤回排队只在软件或真实开放的工具中进行，不等于远端取消 |
| acceptance_unknown | 可能已受理或扣费；先核实原服务请求，禁止换账号、换入口、换 UUID 绕过占用重新收费 |
| resolved | 用户核实结束并人工解除本地占用后，可按授权创建新重试草稿；解除不代表远端取消或退款，再次生成可能重复扣费 |
| output_unavailable | 优先用开放的 image_output_recover 恢复已有结果；不发送新的生图 POST。用户另行明确要求重新生图时，解释可能再次计费后再创建新版本 |
| saved | 已登记素材，不等于质量审核通过；实际看图复核。用户需要修改或重生成时创建新版本，保留旧结果 |

当前 MCP 没有已核实的解除占用工具；指导用户在软件中先核实并解除，随后重新查询状态，只有确认为 resolved 才继续重试流程。不要臆造 resolve/retry/cancel 调用，不直接改 SQLite、删除锁或占用记录。

`image_output_recover` 开放时使用 boardId、id、expectedRevision、confirmed=true 和 requestKey；只启动既有结果的下载归档，随后查询状态，不把诊断成功或启动下载当作已保存。

`image_nodes_submit` 开放时提交同一 boardId 的 `{id, expectedRevision}` 列表及 requestKey；它会自动执行，不能当作保存草稿工具。提交前已有明确图数/服务/费用及参考外发授权才调用；费用未知时明说。一次请求响应丢失时先查询，必要时用同一请求键幂等重查，不换键重复收费；已获准的新生成尝试才使用新任务与新请求键。遇到新超时、受理不明或明确失败即停止该尝试并回报，不能把“允许重试”理解为无限自动重试。

删除仅限明确授权的任务和最新 revision，使用已开放的 `image_nodes_delete`：boardId、nodes、requestKey。在途或受理不明任务拒绝删除；删除后回读列表，不能把软删除当作取消、退款或释放远端任务。工具缺失时保留现状并报告，不绕过权限。

## 查到素材不等于已看图或能上传原图

`assets_list` 返回元数据，不代表已经查看图片。发现 `assets_read_image` 后，先查询目标素材的最新 `updatedAt`，再传 `assetId` 和 `expectedUpdatedAt` 读取并实际查看原图；修订冲突时重查元数据，不沿用旧修订。该工具不接受路径、不提供任意磁盘读取，`assembly_inspect_media` 仍只处理视频/音频。禁止猜应用私有URL或遍历受管磁盘绕过边界。

原图工具未开放、权限不足或文件不受支持时，再使用已授权的受控图片资源，或请用户提供原图/明确授权的本地路径；不因工具缺失扩大权限。未知像素内容标注未查看。视频截图可用于取证，不擅自将低清截图当作人物/风格原图基准。

把素材上传到生图服务，还需本次参考图生成及外发授权；素材 MCP 的只读/写入授权不包含外发图片，也不包含图片或视频付费生成。只有元数据时可整理候选清单，不能声称已将素材库原图用于生图。

## 参考图到视频草稿

先查复用候选并实际查看 → 判断图的职责和版本 → 对缺图提出生成计划 → 获准时可先在工作台创建本地生图草稿，另获生成/外发许可才提交；无工作台执行能力且用户选用包内脚本时按图片模块执行 → 实际看图检查 → 工作台已登记素材直接复用，外部文件仅在已授权导入后复制到授权目录并 `assets_import` → 绑定到指定视频草稿 → 用返回标签编译提示词并按最新 revision 保存。目录不匹配时请用户选择合适导入目录或明确授权复制，不自动移动/覆盖原件。

同一项目不同镜头各自绑定相应机位图；长镜头后段等待真实前段末态。无 MCP/只读/会话过期时停在受限步骤，继续交付图片文件、声音计划和待绑定说明，不伪造成功，也不将生成和导出权限顺带打开。
