# 参考图生产与多服务账号

用户要求角色生成、五视图或人物转面时，完整读取 [角色生成：固定五格设定图](references/character-five-view.md)，使用其中的视角、布局与验收规则；账号、生成授权和失败图处理仍遵循本模块。

合入本地 online-image 的接口、尺寸与脚本，不依赖安装原技能；没有复制任何真实 Key。本模块不负责视频付费提交。生图服务、账号和任务上限以用户当前配置为准，不自动查额度或发送收费测试请求。

## 先确认基准和图片职责

完整读取 [项目统一视觉风格与图片重生成](../storyboard/references/project-visual-style.md)。先复用已批准风格/人物/空间基准；缺失批准时停在风格提案与已授权试样。每张图明确服务的镜号/生成段、机位、画框、时刻与职责（身份/空间/风格/开场/动作/结束），不让一张静态图承载互斥时刻。

有工作台连接时读取 [MCP 接入](../../references/workspace-mcp.md)，先查库复用，再实际读取合格图片。仅查到元数据不能生造原图路径。没有 MCP 时用用户提供的本地原图，或交缺图清单，不阻塞文字设计。

## 选择执行端

已连接工作台且用户要求在那里准备或管理素材时，优先查询/复用素材生成任务组，通过已开放的 MCP 工具创建本地草稿、读取状态和结果。软件界面已改为任务网格与右侧编辑区；MCP 的 board/node 名称为兼容协议，不要求操纵无限画布。具体字段、版本来源、重试及恢复下载见 [MCP 接入的素材生成章节](../../references/workspace-mcp.md#素材生成任务组版本与重试)。

创建草稿不等于生成授权；已有草稿、请求超时或受理不明都不是改用包内脚本重新收费的理由。以下账号配置、providerId 分发和本地共享并发池规则只适用于包内脚本，不用于读取或复制工作台账号配置。工作台生成结果已登记素材时直接查询/读取，不重复导入。

生产顺序按依赖：批准风格 → 合格人物/场景等基准 → 相应镜头图 → 实际看图校核 → 用户所需交接。已具备全部依赖的非连续镜头图可并发；未批准基准、未检查图、失败图及其派生图不能自动喂给下游。长镜头后段不预生独立开场帧覆盖未来真实尾帧。脚本不替人判断审批或导演依赖，只执行已经就绪的显式批次。

## 账号配置和分发

使用包内 `scripts/image_batch.py`，默认配置是本模块 `config/image-providers.json`（相对脚本定位，不受工作目录影响），从 `config/image-providers.example.json` 复制后由用户在本地填写。默认直接在每个 provider 的 `api_key` 字段填写 Key，不要求环境变量或独立 Key 文件。没有配置/Key 时停止网络请求，告诉用户实际配置绝对路径、缺少的 provider ID 和凭据字段；兼容旧配置时报告对应 keyFile 路径或 apiKeyEnv 名称。不要让用户把 Key 发到聊天里，也不能因为默认配置缺失就断言用户所有位置的 Key 数为零。

每项配置包括唯一 `id`、`baseUrl`（不带 `/v1`）、`maxConcurrency`（默认2）、`model`（各站实际模型名），默认使用非空单行字符串 `api_key`。`accountGroup` 可省略，默认每个 provider 是独立账号；只有明确知道多个 Key 共享同一真实账号额度时才设成同组，同组 maxConcurrency 必须相同。用户明确3个 Key 是3个账号时应独立计数，例如每账号2、全局6；不按服务地址相同而合并账号。为兼容旧配置，仍支持 keyFile 或 apiKeyEnv，但三个凭据字段只能出现一个。keyFile 相对配置定位，文件只含单行 Key；环境变量只读指定名称。全局上限默认2，可按用户确认的容量配置，不能仅凭 Key 数量猜额度。

检查 Key 数量时只在用户指定的配置范围内读取，由本地脚本统计已配置条目、非空且格式合格的凭据、去重 Key 和账号组数量；不输出密钥、完整配置或密钥片段。仅本地配置检查不等于线上有效、余额充足或服务兼容，不发送收费测试。不得把真实 Key 写进 SKILL.md、示例、任务 JSON、提示词或输出记录。

示例只含 `.invalid` 地址和环境变量名，不填真实密钥。同模型的兼容性由用户/实际证据确认，不能只凭名称；不同站模型别名可不同。将 `modelFamily` 写成已确认的同一模型身份，提供者实际 API 名放 `model`，两者不互相替代。若未确认同模型或参数兼容，不跨站分配同一作品。图片身份/场景基准和强一致性的一组镜头优先固定同一 provider；确需分配则显式给每个任务 providerId，不自动换站或切模型。

真实配置与 Key 文件是用户本地私有文件，不是可分发技能资源；打包时排除 `image-providers.json`、所有 Key 文件、环境变量、运行锁、`.image-concurrency.sqlite3` 及其附属文件、图片原始响应及用户任务/输出，只分发干净示例与代码。不要从旧 online-image 目录搜索/搬运凭据，不修改用户级设置。单图旧入口可显式 `--key-file` 指定原两行格式（第一行地址、第二行Key），但本批次入口使用单行 Key 文件，二者不可混用。默认推荐批次入口，避免命令行 `--api-key` 泄露。

## 显式就绪批次

读取 `config/jobs.example.json` 的结构。任务含唯一 id、明确 providerId、generate/edit、完整 prompt、size；edit 用 images 列出本机合格原图绝对路径，无参考时用 generate。输出目录是绝对路径，实际文件落到新建的唯一批次/任务目录，不覆盖历史。一次任务只请求一张图（n=1）；多张独立图写成多个任务，便于限流和逐图审核。相同批次不自动重跑，续作由用户核对结果后建立仅包含获准任务的新批次。

默认仅预检，检查配置、凭据是否存在、任务、尺寸及参考文件，不联网、不输出 Key 或完整配置：

```text
python <模块绝对路径>/scripts/image_batch.py --jobs <任务文件绝对路径>
```

只有用户明确授权本批次图数、服务和参考图外发/费用范围后，才加 `--execute`。没有固定报价时说明费用未知，不伪造预算。检查是否还有其他客户端消耗账号并发，脚本只能限制本模块自身提交。

允许多个聊天、进程和批次同时执行。批次不是并发额度：按每个实际在途请求计数，通过本模块 `.image-concurrency.sqlite3` 的短事务原子领取全局和账号额度；有空位立即提交，满额才排队，不再用批次独占锁，也不能只删除锁后让各批次分别计算6并发。任务仍需预先显式指定 providerId，不自动换账号、换站或重试。外部应用和不同技能安装副本不在共享额度范围，应另计其实际占用。

升级时，旧版本已运行的进程尚未登记共享额度：保留其 `.image-batch.lock` 并让旧批次正常结束，不能删除活跃旧锁硬启动新版；这是一次性的升级过渡，不是新版限制多批次。异常退出、受理不明请求保留额度，不按超时或 PID 消失自动放行；先用 `--concurrency-status` 查 token、状态文件及暂停账号。核实远端请求已结束并获用户明确允许后，才用 `--release-confirmed TOKEN` 归还相应额度；401/403/429 暂停该账号跨批次的新提交，核实并获准后用 `--resume-account-confirmed ACCOUNT` 恢复。状态查询和人工归还只操作本地记录，不重新生图。完成响应后的图片下载失败不自动重提；受理不明、崩溃及中断均可能已计费，停止本地进程不代表远端取消或退款。

## 接口、尺寸与结果

仅用 Python 标准库，无自动依赖安装。无参考调用 `POST /v1/images/generations`（JSON）；有参考调用 `/v1/images/edits`（multipart，image[] 可重复）。返回支持 data 内或顶层的 url/b64_json；下载不携带服务 API Key，不跟随付费 POST 的跳转以免凭据外泄或重复受理。地址默认必须 HTTPS，不猜测 API 变体；兼容性失败报告，不擅自改接口重新收费。

尺寸白名单沿用 online-image：

- 1K：1024x1024、1280x720、720x1280、1280x800。
- 2K：2048x2048、2048x1152、1152x2048、2560x1600。
- 4K：2880x2880、3840x2160、2160x3840、3584x2240。

选适用的最小档，4K 仅明确需要时使用；白名单不是所有兼容服务都已验证支持的保证。实际模型由用户选定，不在跨站批次用 `auto` 猜测同模型。

脚本只报告任务ID、provider ID、状态和本地输出，不记录密钥、远端响应正文或带签名下载URL。执行前落本地计划、每个请求前标记 submitting；有 submitting 而无完成记录时视为受理不明。保存成功也不代表图片质量批准：实际查看人物身份、机位、动作时刻、空间、光色、风格与参考职责；失败按风格资料回到合格基准，重生成须在授权内。

向用户展示保存图使用绝对路径 Markdown 图片，交接图→镜头/生成段→草稿关系、使用的基准和未核验项。导入素材库和绑定草稿需额外满足本轮授权/MCP范围；无 MCP 交本地图片与待绑定清单，不伪造上传或保存成功。
