# MCP 接入约定

## 视频理解 MCP

视频理解工具用于：

- 长素材语义检索；
- 定位人物、动作、物体、对白和画面文字；
- 生成带时间戳的章节、摘要和候选片段；
- 跨素材相似镜头检索。

使用原则：

1. 所有返回片段必须落到本地源路径或稳定视频 ID 和时间范围。
2. 语义搜索结果必须由本地解码帧复核，尤其是小于 2 秒的动作和微表演。
3. 当云端时间戳与本地 PTS/帧号不一致时，以本地解码证据为准并记录偏差。
4. 未经用户授权不上传敏感素材。

### TwelveLabs 当前入口提示

配置时以官方 MCP 页面显示的客户端配置为准。不要在 Skill 中硬编码 API key。将密钥放在 MCP 客户端的安全配置或环境变量中。

## DaVinci Resolve MCP

用于：

- 查询项目、媒体池和时间线；
- 复制/版本化时间线；
- 导入、重连、插入、覆盖、替换和修剪；
- 添加标记；
- 调色、Fusion、Fairlight 和渲染；
- 读取修改后的状态并验证。

### 执行约束

- 先查询能力和当前状态，不假设工具名称；
- 默认使用较紧凑的 compound server，只有明确需要时才使用 granular surface；
- 每次修改前复制时间线；
- 每批修改后重新读取实际片段位置；
- 不自动删除媒体、项目或原时间线；
- 工具不可用时输出 EDL/CSV/JSON，而不是假装已应用。

## 推荐任务调用顺序

```text
本地 analyze_video/analyze_folder
→ Codex 检查接触表
→ 视频 MCP 语义检索与补充
→ 本地对候选区间高密度复扫
→ Codex 生成 edit_plan.json
→ schema 验证
→ Resolve MCP 复制时间线并应用
→ 回读时间线与 changelist 验证
```
