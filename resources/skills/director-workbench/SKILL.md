# 导演工作台

围绕同一作品，把剧本、分镜、参考图、生成片段和剪辑决策衔接起来。按当前请求选择模块，不为一次局部修改重走整条流程。分镜、提示词、剪辑和参考图模块及参考资料都在本包内，不依赖安装原来的独立技能。

## 输入路由

先结合最新要求和当前上下文判断交付物，用一句话告知本轮使用哪些部分，然后完整读取对应模块入口及其适用参考。未选模块不预加载。

| 用户要做什么 | 读取与执行范围 |
|---|---|
| 拆剧本、设计/修改分镜、安排长镜头或切镜、规划分镜图与转场 | [分镜模块](modules/storyboard/guide.md) + [分镜剪辑与声音交接](references/storyboard-edit-sound.md) + [剪辑判断规则](modules/editing/references/editorial_rules.md)；在生成前设计可剪性，不启动真实素材分析或剪辑 |
| 生成/修改参考图、配置生图地址与多 Key、批量出分镜图 | [参考图模块](modules/images/guide.md)；按依赖生产，配置和生图分开授权 |
| 角色生成、角色五视图、人物转面设定图 | [参考图模块](modules/images/guide.md) + [角色生成](modules/images/references/character-five-view.md)；固定上二下三：上排两张脸部，下排裁掉头部的正侧背服装视图，不是五个全身角度 |
| 写/改视频生成提示词、设置连续属性、绑定前段视频/尾帧、保存生成草稿 | [提示词模块](modules/prompt/guide.md)，并读其中的 Ref2VA 格式；继承已定分镜，不重新导演 |
| 看成片衔接、光色/机位跳变、重复动作声音、挑选素材、节奏与剪辑/导出 | [剪辑模块](modules/editing/guide.md)；先取证，再按请求给方案或非破坏执行 |
| 从剧本做分镜并写提示词 | 分镜 → 提示词；分镜图描述先确定实际机位和时刻，再写该段生成文本 |
| 检查生成结果并改下一版提示词 | 剪辑取证 → 提示词；只有根因在未锁定分镜时才补读分镜模块，明确提出变更 |
| 从剧本做到剪辑/成片 | 按缺失环节逐段推进；无真实素材时停在计划和提示词，不把计划写成已生成或已剪好 |

“只改第二段提示词”不启动全片重拆；“看看是否连续”不授权剪辑；“先拆分镜”停在分镜。“继续”沿用已明确阶段，不自动升级到生成或导出。只有关键意图、版本或连续性确实无法判定且会实质改变结果时，才询问必要问题。

分镜阶段主动融合剪辑经验，不等待用户另喊剪辑技能；每个相邻接点判断长镜头续接或有动机切镜，每镜交付声音与后配计划。仅借用剪辑判断不要求真实素材、分析脚本或 NLE。无素材的切点/声音时长是设计估算，不是已验证结果。

使用工作台素材、剧本、草稿、素材生成任务组或排片时读取 [可选 MCP 接入](references/workspace-mcp.md)。查询缺图、建生图草稿、检查结果、重试及恢复下载按其中的素材生成规则执行。MCP 不是必装依赖；未连接时继续文本与用户提供的本地媒体流程，不阻塞分镜、不伪造素材标签或保存状态。

## 共用约定

- 默认中文；保留用户原对白、歌词、可见文字及协议英文标签。保留已认可的剧情、风格、时长和拍法，局部修改只动受影响范围。
- 分清叙事节拍、剪辑镜头、模型生成片段；不按每段 5 秒机械切镜，不把全部对白强制做成长镜头或正反打。拍法由信息、表演、情绪和空间关系决定。
- 分镜承载导演意图和净时间轴；平台提示词负责忠实编译；实际素材决定剪辑入出点。不能用新提示词倒推历史任务输入，也不能用漂亮单帧证明整段可剪。
- 涉及台词、声线或人物情绪时，读取 [台词、声线与有因表演](references/dialogue-performance.md)。无音色引用时定义稳定声线，逐句设计语气、节奏、状态与标点；情绪由角色实际看到、听到或经历的事件触发，落到动作、表情和说话语气，不凭空出现。
- 连续镜头继承真实前序末态，不重演已完成动作或声音。同一场景切镜不等于同一镜头延续；反打可改变构图，但世界空间、轴线、视线与光源仍应成立。
- 参考和提示词不能保证跨次生成的机位、透视、光照完全一致。调色、稳定和叠化各有边界，不用“保证无缝”代替实测。

## 模块交接

已有可靠信息直接继承，不强制用户补一套表单，也不另建与工作台冲突的平行业务数据库。跨模块时传递本次实际需要的以下信息：

- 项目、剧本/草稿修订、镜号、前序镜号、具体任务/素材版本；未知项明确标注，不凭“最新”猜版本。
- 分镜净时间轴、镜内动作/对白时间、切点原因、当前与下一段的连续关系，以及起态/尾态、轴线、机位和光色锁定项。
- 逐镜声音清单、生成内允许声音与后配声音、绝对/镜内时间换算、跨镜声音桥和待找素材；后配不等于让视频模型再生成一遍。依赖实际前序结果的长镜头后段，不预先伪造最终绑定稿。
- 参考图/视频/声音各自职责、真实绑定标签、来源任务与源区间。静态图的开场/关键动作/结束职责分开，不用一张图表达互斥时刻。
- 目标净时长 T、生成请求 G、实际输出 D、参考长度 L、计划余量 H、实测重复 O、有效新内容 U 分开记录。引用长度不等于重复长度，不能固定盲切，也不能静默补长计费。

分镜进入 H3 提示词时，强制采用 h3-prompt-writing 的 Ref2VA 六节，单张首帧也不切换三节，不新增模式选择。先中文确认，确认后英文写入草稿；对白、歌词、画面文字保持原文。保留表情、声线与声音公式。当前 `shotContinuity` 与 `nextTransition` 分别判断；首段 independent 仍可为下一段准备 continuous 尾段。软件实际契约优先，不臆造工具或字段。

尾段规则集中维护在提示词模块：默认最后 1 秒，上限 `min(2秒, 来源实际时长×25%)`，整数工具向下取整，真实同源末帧、默认无音轨。剪辑和分镜不得另设冲突上限，也不能把完整参考伪装成尾段续接。

## 工具、权限与完成状态

- 直接连上工作台 MCP 后，先按接入指南调用 `assets_import_directory` 获取当前授权导入目录；本地参考图导入前重新查询。不得猜测临时附件目录已获授权；导入、绑定和付费生成分开确认完成状态。

- 优先当前视频工作台 MCP；先发现能力、确认授权项目、媒体来源与最新修订。软件有尾段衍生、取帧、剪辑、导出能力时使用软件，不另写 FFmpeg 裁切脚本。随包脚本是可选工具，不因加载技能自动执行、安装依赖或切换到其他软件。
- 生图允许多个批次共用已配置的并发额度，不按批次数量限流；独立账号分别计数。包内脚本使用其显式 providerId 与共享额度；工作台 MCP 使用其真实 accountId 契约，允许时以 null 交给工作台自动调度，不混用脚本配置与软件账号池。异常占用和重试按各自执行端的状态处理，不通过换入口绕过限制。
- 写提示词、保存草稿、生成图片、上传素材、付费生成、修改时间轴与导出是不同动作，各自只在用户已授权范围执行。此技能本身不授予付费权限，不自动补拍或重试计费，不扩大 MCP 授权，不读取工作台账号密钥或客户端认证配置。获准生图时仅由包内脚本读取用户指定的生图凭据，不回显或搬运到交付物。
- 现有素材不覆盖，剪辑保留可回退版本；保存前核对修订，冲突后重新读取并保留用户修改。仅咨询不改业务数据。
- 抽帧只能证明对应时间的画面；波形、音轨信息或用户报告不等于独立听审。分别说明已观察、推断、已保存/绑定、已应用剪辑、已导出与未核验项，不虚报完成。
- 如果缺少素材、权限或工具，交付仍能完成的分镜、文本建议或剪辑计划，并明确缺口。不能伪造引用标签、真实取帧、听审或导出结果。

## 包内路径与来源

模块入口中的 `references/`、`scripts/`、`schemas/`、`assets/` 相对于该入口所在模块目录，而非本包根目录。引用在包内即可读取；工具示例是说明，不代表当前已开放能力。

- 分镜：基于 `62656456/ai-film-skills` 的 `ai-storyboard-director`，版本 `f1fee0587e985fa81eedc3be7d7258a9a39a2ed3`，许可保留在 `modules/storyboard/LICENSE`。
- 提示词：合入本地 `rh-video-prompt-writing` 的当前中文、引用、尾段与声音规范。
- 剪辑：基于 `Skylinekimi/cinematic-stream-editor-skill`，版本 `949689aff8d18a2f8e56a412dd9927192dab285d`，许可保留在 `modules/editing/LICENSE`。
- 参考图：合入本地 `online-image` 的接口、尺寸白名单和单图脚本；新增多地址/账号限流、显式批次执行及无密钥分发配置，不携带原技能凭据。
