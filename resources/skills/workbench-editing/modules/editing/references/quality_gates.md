# 最终质量门禁

## 分析门禁

- [ ] 每个被使用的素材都经过 ffprobe；
- [ ] 每个入选镜头都有实际解码关键帧；
- [ ] 重要微表演区按足够帧率复扫；
- [ ] 镜头边界不是仅凭低频采样决定；
- [ ] 音频存在时已检查波形/能量/对白位置；
- [ ] VFR、时间码缺失和异常流已标记。

## 剪辑门禁

- [ ] 每个 cut 有明确理由；
- [ ] 关键动作、视线和空间关系已检查；
- [ ] 有意跳切/越轴已标注目的；
- [ ] 音频桥接和反应镜头已考虑；
- [ ] 关键镜头留有可调整把手；
- [ ] 备选 take 已记录。

## 工程门禁

- [ ] 原始素材未修改；
- [ ] Resolve 原时间线未覆盖；
- [ ] 时间线 FPS、起始时间码和音频采样率正确；
- [ ] 实际时间线和 edit plan 已比对；
- [ ] 变更清单已生成；
- [ ] 最终渲染前完成画面、声音、字幕和交付 QC。
