# 示例：人类工厂素材粗剪

2026-10-23 合并适配：以下为上游虚构项目示例，不是当前作品要求；统一从导演工作台进入剪辑部分。

```text
$director-workbench

分析 `D:/HumanFactory/Footage` 下的全部素材。

目标：建立 45 秒叙事粗剪，不修改 Resolve。重点识别：
1. 流水线动作最整齐、构图最有压迫感的建立镜头；
2. 734 号工人出现 0.2–0.5 秒节奏偏差、眼神下移或手指松开的 take；
3. 笔落地的动作、结果和其他工人微反应；
4. 机器人孩子观察、模仿和把笔交给父亲的无台词表演；
5. 可以用环境声或机械节拍做 J-cut/L-cut 的片段。

全片先 4 FPS 扫描；上述候选区按源帧率复扫。输出 shots.jsonl、接触表、selects.csv 和 edit_plan.json。每个 cut 必须写明理由和备选镜头。
```
