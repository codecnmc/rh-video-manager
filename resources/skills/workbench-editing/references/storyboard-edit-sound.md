# 分镜、剪辑与声音一体设计

出分镜和修改跨段衔接时必读，同时读取 `../modules/editing/references/editorial_rules.md`。这些是生成前的导演与剪辑判断；真实素材仍须后验，不启动 NLE 或付费操作。

## 先决定镜头，再决定生成批次

先按叙事、表演与观看关系决定长镜头/切镜，再拆模型生成片段。镜号与生成段号分开：一个镜头可跨 A/B 段，一段也可能含已设计的切点。给出每段归属、净时间和参考图职责，不机械按秒数切镜。

- 长镜头：实时表演、空间关系或等待本身有价值时保留。运镜可在镜内转向、变速、换关注主体，不必切镜。接点设计人物/道具末态、动作相位及速度、摄影机位置/朝向/高度/运动趋势、主体尺度、地平线、光色和背景地标；下一段从下一时刻继续，不重新起演。前段尚未生成时只写预计状态与待验证依赖。
- 同场切镜：按信息显露、反应、注意力或权力转移选切点。可换机位景别，保持轴线、视线、屏幕方向、动作相位及世界光源。动作中切、反应/插入、正反打按实际叙事使用，不强求两幅图一致。
- 时空转换或故意断裂：明确省略了什么、观众如何理解，选择硬切、声音桥或有意义的转场。叠化不是常规补缝工具；甩镜、遮挡接点须设计两侧的方向、速度、遮挡覆盖与揭示时机，不能只写“自然过渡”。

每个关键接点交付：`前镜/生成段 → 后镜/生成段｜连续关系与切点理由｜前尾态→后起态｜画面接法｜声音接法｜余量与风险`。无重要风险可简写，不堆空栏。

生成前检查：切点是否抢掉思考/反应或截断对白；下一段是否重复已完成动作；运镜是否在段界突然停住/重启；反打是否越轴；是否有可用声音桥。需要剪辑余量时说明用途和预计量，单列净时长与请求时长，增加付费时长必须另获同意。不能把引用长度当重复长度，不能用定格/慢放/循环冒充缺失内容。

已锁定长镜头不擅自改切镜。可提出有叙事依据的备选覆盖位置，明确是未采用方案、是否缺图/素材、是否额外计费；没有授权不生成备用素材。

## 每镜声音必须能交给后期

涉及对白或人物情绪设计时，必读 [台词、声线与有因表演](dialogue-performance.md)，先确定事件刺激与感知，再安排动作、表情、说话语气及对白节奏；把稳定声线与本句状态一起交给提示词或后配，不只交付抽象情绪词。

分镜主表仍用简洁声音摘要，另附有实际需求的声音清单。每镜都判断对白/人声、拟音/瞬态音效、环境底声及音乐，不要求每类都有，也不为静止道具凭空加声。无声是有意决定时写明。

推荐清单：

`声音ID/所属镜段｜类别与具体声源/音色｜镜内起止与成片起止｜画面同步点｜生成内/后配/待定｜跨镜方式｜素材来源与状态`

- 描述可寻找或制作的声音，而非“震撼音效”：例如近距离木门锁舌短促金属弹响，触发于锁舌脱开；室内干声或有空间混响，远近与画面相符。需要时给检索词/拟音制作描述，不虚构音频文件或授权许可。
- 本轮用户要求音效后配时，动作拟音/强调音效默认后配；对白、呼吸等人声、环境底声及音乐分别决定，不能把“音效后配”解释成全部无声。音乐未批准不擅自创作/添加。
- 无素材时以动作同步锚点为主，秒点和时长标为估算；收到实际视频后重新定位。生成余量、裁切和改镜序后重算声音落点，不能沿用旧时间码。连续底声用一条跨镜声音需求，不每镜重复启动；瞬态声用唯一事件ID，避免重复门铃/撞击。
- 后配音效写清目标质感、同步动作、远近/空间、是否保留原声。音量先写相对主次，不伪造已测响度或精确混音值。音乐、环境声、对白被混进原片时，不能承诺独立删声无损。
- 生成内声音只列本段允许项；后配项在视频生成文本中明确不生成，画面动作仍然保留。后期要求放在独立制作表，不混入让模型执行的声音白名单。
- 声音桥明确来源和去向：J-cut 是后镜声音先入，L-cut 是前镜声音延续。设计跨界区间，检查对白、口型、场景声学和叙事动机；实剪只用真实可用余量。环境声跨镜可连接空间，不能让已结束事件再响。

## 参考图、视频稿与后期交接

非连续镜头：共享已批准身份/场景/风格基准，各镜使用对应机位和实际时刻的参考图；依赖齐备后可并行生图、填写各自视频稿。正反打仍相互校验空间，不因独立生成而随意改变道具和光源。

同一长镜头跨段：先排完整表演和运镜，只有首段使用设计开场图；后段最终参考以真实前序尾段及同源末帧为准。末帧选择与尾段长度遵循提示词模块，不在这里另设上限。失败/未确认视频不自动成为下一段基准。

交付分镜时一并交接关键接点表、逐镜声音清单、图片职责及待完成依赖，保留用户原对白与批准决定。已有制作表按原格式补齐，不另建数据库。MCP 写入只用软件真实字段：目前排片声音可记录 `evidence` 依据及 `missing/review/bound/original/none` 状态；未有真实视频时不虚构 `assetId/sourceDuration` 来保存排片。计划先交文本，实际媒体到位且用户授权后再落库。
