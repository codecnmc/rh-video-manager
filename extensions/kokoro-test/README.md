# Kokoro 本地语音接入测试插件

本地 CPU 中文语音测试插件，当前版本 0.2.1，供带“台词音频”生产入口的新版本工作台使用。不支持音色克隆、情绪指令、H3 时间轴自动提取或时长拟合。无需联网推理，也不会自动下载模型。能力限制不是可通过配置开启的隐藏功能。

## 打包版安装

1. 启动 `win-unpacked/AI 视频工作台.exe`。整个 `win-unpacked` 目录须一起保留，不能只复制 EXE。
2. 在“插件”中点击“安装本地插件”，选择配套 `plugin-support/kokoro-test` 目录，阅读并确认信任。
3. 在该插件的设置中，将“独立运行环境目录”填为配套 `plugin-support/runtime` 文件夹的完整绝对路径。该文件夹中应直接包含 `runtime.json`、`python` 和 `model`。
4. 可选：设置测试文字（最多 120 字）、中文音色 ID（45–48 女声、49–52 男声，默认 45）与语速（0.5–2，默认 1）。保存后启用插件。
5. 点击“查询音色”验证激活；点击“生成中文测试 WAV”，在确认框中明确执行。完成后点击“打开测试输出目录”查看和试听 WAV。

已有 0.1.0/0.2.0 插件需要先卸载登记，再从新配套目录安装 0.2.1 并重新配置；不可直接编辑 userData 内的不可变包。历史音频不会删除。新的宿主链路仍可以调用旧插件生成短句，但 0.1.0 清单没有单次 120 字限制的前置声明。

## 草稿生产入口

1. 保存视频草稿，切换“生成设置 → 台词音频”，启用台词音频步骤。
2. 添加台词，或导入台词 JSON；也可从素材库选择保存了台词 JSON 的提示词素材。
3. 每句选择 Kokoro 引擎，点击“载入音色”，选择预置音色，保存配置。单句最多 120 字，语速为 0.5–2。语气描述必须为空，否则宿主拒绝生成，不会悄悄忽略。
4. 点击“生成台词”。音频独立排队，不会调用视频生成；可离开当前草稿，在任务队列的“台词任务”查看进度。
5. 成功音频自动进入当前项目素材库并作为该草稿的候选；在候选记录内试听、再次生成和明确采用，不覆盖旧音频。

台词 JSON 格式：

```json
[{ "character": "旁白", "startMs": 0, "text": "新的故事，现在开始。", "delivery": "" }]
```

`startMs` 仅记录台词的目标起点，当前不自动拉伸、裁剪或合并音频，不等于音视频已经完成对齐。项目角色音色可复用；生成时按当次台词配置保存快照。更改配置、提示词或模型后，旧候选保留，但不得直接采用到新修订。

以下目录区分：插件面板里的诊断命令仍写入 `extension-data`；草稿生产写入受管素材库 `assets`，并把任务和候选登记到 SQLite。采用候选只建立生产选择关系，不会自动添加 H3 的 `<Audio>` 引用、上传或重新提交视频。

输出为 24kHz、单声道、16bit WAV，写入软件用户数据目录 `extension-data/workbench.kokoro-test/`；文件名带 UUID，不覆盖旧文件。插件包自身保持只读。停用、卸载、重装不会删除这些测试音频。

生成使用独立的 CPython 3.13.9 x64、sherpa-onnx 1.13.8、NumPy 2.2.6 和 Kokoro INT8。不需要系统 Python、Anaconda、Node.js、pip、CUDA 或开发项目路径。只支持 Windows x64；首次使用可能受系统安全软件、文件权限或缺失系统运行库影响，不承诺跨平台或所有机器兼容。

插件代码与运行环境分开：插件包约几 KB，可通过同一入口安装到开发版或打包版；权重与解释器不放进 app.asar，不受插件包 32MiB 上限影响。配套目录可以移动，移动后须在设置里更新运行环境绝对路径。清理开发目录的 `.cache` 不影响已经复制出的配套运行环境。

插件是全信任本机代码，不是权限沙箱。请勿将生产账号密钥配置给这个无联网需求的测试插件。音色为模型内置预置音色，不代表用户已进行克隆或拥有某位真人的身份授权。第三方来源和许可证说明见同目录 `THIRD_PARTY.md`。
## 0.2.1 更新说明

打开测试输出目录改用宿主 `openStorageDirectory()`，由主进程检查系统打开结果。需要本次更新后的工作台宿主；已安装包不会随源码更新，请显式卸载旧版后安装本目录的新版本，并重新配置运行环境路径。卸载保留历史输出、受管素材和独立插件存储。
