# README 截图位置

本目录保存 README 使用的脱敏实拍。原图仅保存在开发者本地被忽略的 `.cache/private-screenshot-originals/`，不随仓库分发。图片为重新编码的无元数据 RGB PNG，遮挡直接写入像素，不保留隐藏图层。

| 文件名 | 建议画面 |
| --- | --- |
| `视频生成.png` | 视频生成：草稿、参考素材、预览与状态 |
| `排片剪辑.png` | 排片剪辑：素材区、播放器和时间轴 |
| `素材生成.png` | 素材生成：任务组、图片节点和版本 |
| `素材管理.png` | 素材库与分类 |
| `账号池.png` | 账号与额度管理，敏感字段已遮盖 |
| `工作流.png` | 工作流总览：下载与添加入口 |
| `mcp.png` | MCP：范围和权限概览 |
| `skill.png` | 分开安装或导出的内置技能 |
| `多窗口.png` | 独立工作台窗口 |

只保留软件窗口。用不透明色块遮挡账号名、ID、余额、Key、Token、MCP 配置、个人路径、项目及剧本文字、私有工作流 ID、未授权的素材与人物信息，不用可逆图层或仅模糊处理。导出为新的无元数据 PNG，并放大复查。

不要将原始截图、用户数据库、日志或迁移包放进本目录。这里是公开文件，会进入 Git。
